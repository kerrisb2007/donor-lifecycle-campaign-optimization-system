Project Overview
---

This repository will contain an end-to-end data engineering and business intelligence solution designed to optimize fundraising operations for a philanthropic foundation. Utilizing Oracle SQL on the backend and Tableau on the frontend, the system models donor behaviors, evaluates marketing campaign performance, and surfaces actionable insights for leadership.

• Project Status: In Progress
• Target Completion: Mid-November 2026

Dataset Source
---

This project utilizes clean, transaction-level donor history records from the following open-source dataset:
[Kaggle Synthetic Donor Dataset for Fundraising Analytics](https://www.kaggle.com/datasets/dbrown86/synthetic-donor-dataset-for-fundraising-analytics)


Core Business Use Cases
---
This analytics suite will resolve two critical challenges faced by enterprise philanthropy divisions:
• Donor Attrition & Churn Prevention: Groups donor profiles using SQL-driven RFM (Recency, Frequency, Monetary) behavioral scoring to automatically isolate high-value, lapsed donors for proactive outreach.
• Marketing Campaign ROI Optimization: Links transaction records to marketing channels (Email, Direct Mail, Gala Events) to calculate the Cost Per Dollar Raised (CPDR) and identify high-return fundraising streams.

Project Roadmap
---
• Phase 1 (Backend): Relational database architecture, data engineering view creation, and behavioral segmentation scripting using Oracle SQL analytical functions.
• Phase 2 (Frontend): Interactive visual design, parameter implementation, and cross-filtering action setups within a 3-tab executive Tableau Public dashboard.
